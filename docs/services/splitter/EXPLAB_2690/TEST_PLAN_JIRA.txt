Загрузить новую версию конфигурации, проверить HTTP 200 / LOADED, выполнить split с splittingId нужного диапазона, проверить HTTP 200, версию, состав объектов и ожидаемый результат строки. После сценария приложить runtime metadata, ConfigMap и текстовый лог pod нужного сервиса; при сбое — события. Восстановить управляемое состояние.
