# EXPLAB-2690: четыре требования заявки

Приоритет: формулировка заявки и уточнения заказчика. При разделении не менялись
ожидания существующих основных тестов и согласованный допуск no-MAIN filtered=false.

| Требование | Основные проверки | Что подтверждается |
|---|---|---|
| MAPPER без MAIN как несвязанный объект | NoMain, WorkedGroup NONE, MixedObjects; true/false | Объект сохранён, objectResults absent/null/[], нет MAIN[] и ALL; нет фильтрации true |
| Альтернативный MAIN использует группу связи объекта | MapperAlternative, MixedObjects | Точные expGroup, conditionId, параметры связанной группы; не параметры чужой сработавшей группы |
| Отдельная фактически сработавшая группа | WorkedGroup, MapperAlternative, MixedObjects, ReactionsGroups | finalExpGroup существует и соответствует сработавшей группе; обычный и альтернативный случаи |
| REACTIONS без альтернативы | ReactionsNoAlternative, ReactionsGroups; true/false | MAIN только из собственных сработавших групп; отсутствие isAlternative=true; чужая группа не создаёт MAIN |

MAPPER no-MAIN включает missing/unknown/wrong-type/empty actionType, отсутствие сработавшей
группы и смешанные объекты. Непривязанный объект используется как контрольный случай.
Если no-MAIN объект не содержит строк экспериментов, finalExpGroup у него не требуется:
null у связанных несработавших строк Kafka относится к дополнительному контракту extension.

Базовые проверки точного состава объектов/правил, параметров и сработавших групп остаются
частью проверки этих требований. Слои, время и вся логика фильтрации не становятся
дополнительными условиями приёмки заявки.

Источники: текст заявки; Тесты-v10-20261001_195337.pdf; описание split v1.3;
Спецификации Сплиттера-v16-20261003_130355.pdf. Свежая спецификация противоречива:
стр.96 допускает технический MAIN, стр.98 запрещает. Core сохраняет согласованный
контракт, не принимает текущий ответ сервиса как эталон.

48 сценариев не означают 48 отдельных требований и не доказывают 100% всего API.
Спор Kafka ALL при allow=false и расширенная трассировка находятся в ../extension/.
