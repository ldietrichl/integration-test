# EXPLAB-2690: известные расхождения основного контракта

В предыдущем общем DEV-прогоне MAPPER/REACTIONS при отсутствии итогового эксперимента
возвращали MAIN.resultExps=[], у MAPPER C также сохранялся ALL в REST.
Это не соответствует согласованному ответу без MAIN. Core продолжает выявлять это
расхождение; перенос extension его не скрывает и сервис не исправляет.

Исторические 64 падения общего набора нельзя приписывать только ядру заявки:
они включали слои, Kafka ALL и дополнительные матрицы. Прогон после разделения
не выполнялся, поэтому нового числа passed/failed для core здесь нет.

Следующий прогон:
```powershell
.\gradlew.bat explab2690Coverage
```

Проверить 48 результатов (при полном запуске), исходные/восстановленные ConfigMap,
готовность подов и освобождение leases. Ошибки разных объектов не должны маскироваться.
Расхождения resultDt, filtered, Kafka ALL и слоёв описаны в ../extension/KNOWN_DEVIATIONS.md.
