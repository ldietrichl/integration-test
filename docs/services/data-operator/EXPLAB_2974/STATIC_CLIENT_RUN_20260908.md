# EXPLAB-2974: локальная проверка фиксированного клиента 08.09.2026

Ветка `feature/EXPLAB-2974-data-operator`. Runtime подготовки и очистки переведён на фиксированный клиент, не загружающий JAR сервиса. Корпоративные параметры и секреты не использовались для подключения к локальному Ignite.

| Набор | Выполнено | Успешно | Падения |
|---|---:|---:|---:|
| Функциональные сценарии | 70 | 52 | 18 |
| Негативные проверки | 103 | 0 | 103 |
| Всего бизнес-проверок | 173 | 52 | 121 |

Пропусков и aborted нет. Инфраструктурных ошибок — 0. Результаты, HTTP-статусы и тела ответов совпали с запуском `run-functional-20260907-232855-095`: changed/added/removed = 0/0/0. Сервис не исправлялся; его известные нарушения v7 остаются отражены в отчёте. HTTP: 92 ответа 200, 79 ответов 500, 2 ответа 400.

Все 70 наборов очищены. Удалены 464 объекта, 3051 поле, 136 актуализаций и по 140 записей метаданных параметров/источников. Остаток собственных данных каждого набора в пяти кэшах — ноль. Манифесты schemaVersion=3 содержат хэш клиентского runtime и не содержат ссылок на JAR сервиса.

Отдельный эксперимент подтвердил изоляцию двух параллельно подготовленных наборов, отказ от удаления через подставленную точку MAPPER и повторяемое восстановление после частичной REST-загрузки. Новый probe проверил чтение кэшей и совместимость схемы без записи данных.

Поверх предоставленной корпоративной копии скомпилированы 177 выбранных исходников, 28 внутренних проверок прошли. Отдельно выполнен диагностический `DataOperatorLinksConnectionTest` из корпоративной копии с клиентскими библиотеками непосредственно из готовящегося пакета: 1/1 успешно на локальном Ignite. Проверено разрешение нового секрета штатным корпоративным загрузчиком без вывода значения. Для локального подключения корпоративные логин/пароль были явно исключены. Эти 29 вспомогательных проверок не добавлены к 173 бизнес-сценариям.

Проверены 173 Allure result-файла, 186 container-файлов и 173 HTTP evidence-файла, отсутствующих children нет. Полная корпоративная Gradle-сборка и аутентификация на dev с ВАРМ в этой сессии не выполнялись. Локальный профиль использует Apache Ignite 2.18.0 и Kafka 3.9.1; совместимость клиента с корпоративной поставкой Ignite проверяется диагностическим тестом на ВАРМ.
