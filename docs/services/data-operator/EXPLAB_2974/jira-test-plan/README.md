# Тестовый план EXPLAB-2974 в Jira-разметке

F01–F03 содержат 70 функциональных вариантов, V01–V04 — 103 отрицательных, P01 — диагностику Ignite. `traceability.csv` сопоставляет все 174 результата с UUID, классом, методом, вариантом и первичной группой бага.

Полный повтор текущей версии после патча не подтверждён. Legacy и новые тесты транспорта отмечены отдельно и в 174 не входят.

## Вставка в Jira

1. Вставьте сводный план в поле с Wiki Style Renderer, в режиме Text/Wiki. Подробные части можно разместить отдельными комментариями. Цвет задаётся макросом `{color}`.
2. B01–B09/Q01 — группы разбора, а не ключи заведённых задач. Ссылки ведут на якоря соответствующей части. После создания багов замените ссылки реальными Jira URL.
3. Прикрепите к задаче `EXPLAB-2974-IFT-evidence.zip` и `EXPLAB-2974-specification-v7.pdf` из папки `attachments` отдельного пакета `EXPLAB-2974-test-plan-jira-20260910.zip`. Эти доказательства и журналы не хранятся в Git. При вставке частей в разные задачи приложите материалы к каждой из них.

Полный пакет также содержит HTML-просмотр, структурированные ожидания, provenance и контрольные суммы. Он подготовлен в каталоге результатов проекта `BACK/05_outputs_results/EXPLAB-2974-test-plan-jira-20260910` рядом с архивом. Изменять статусы нового прогона следует отдельно от исторической доказательной базы.
