Пустое множество пар у существующего условия означает splittingObjects=[]; пустые условия эксперимента означают сохранённый эксперимент с objectSelectConditions=[]; отсутствие всех экспериментов означает links=[]. objectIdType/parentIdType=null в ожидании — явный JSON null. Во входе используется objectsSelectConditions, в ответе objectSelectConditions.
