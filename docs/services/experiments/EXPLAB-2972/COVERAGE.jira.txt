h1. EXPLAB-2972 — покрытие корпоративного патча

Все 60 номеров имеют исполняемую реализацию: 8 обычных и 52 управляемых. Для 16 ранее операторских номеров добавлены REST/DB/Kafka-проверки и контроль возможностей среды по CONTROL-API.md. Не все проверки исходной строки покрываются автоматически. PASS API-теста не заменяет оставшиеся наблюдения.

Таблица описывает реализованные проверки, а не результаты последнего прогона. Фикстуры создаются через API с полным валидным шаблоном. Недостижимое через API предусловие допускает только адресную подготовку выделенного объекта и последующую проверку; такая подготовка не доказывает успешное выполнение бизнес-перехода.
